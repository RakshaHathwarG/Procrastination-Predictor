# Procrastination Predictor

An AI-inspired machine learning web application that predicts procrastination behavior based on student lifestyle and productivity patterns.

## Features

* Predicts procrastination risk using Logistic Regression
* Modern futuristic dashboard UI
* Multi-section navigation interface
* Interactive analytics and prediction insights
* Feature importance visualization
* Prediction confidence score
* Recent prediction history
* Responsive design with smooth animations

## Input Parameters

* Sleep Hours
* Screen Time
* Study Hours
* Stress Level
* Assignment Completion Percentage

## Technologies Used

* React
* TypeScript
* FastAPI
* Python
* scikit-learn
* Vite

## Machine Learning

The project uses a Logistic Regression classification model trained on a synthetic dataset to analyze behavioral patterns and predict procrastination probability.

## Dashboard Sections

* Dashboard
* Analytics
* Feature Insights
* Prediction Logs

## Objective

This project demonstrates how machine learning can be used to analyze productivity-related behavioral data and generate predictive insights through an interactive web application.
